### 环境修复
- gstack browse 启动报 `Target page context or browser has been closed` 失败。原因：macOS 上 Playwright chromium 的 helper 二进制（chrome_crashpad_handler / GPU helper）解压后 mode=600 缺 +x 位。`chmod -R u+x /Volumes/SSD/cache/ms-playwright/chromium-*/chrome-*/Contents/MacOS/*` 与 `*Helpers/*` 后恢复。
- 浏览器进程被沙箱挡掉，加上 `GSTACK_CHROMIUM_NO_SANDBOX=1` 后能正常启动。
- 已把这条经验写到 `~/.gstack/projects/ai-bi/learnings.jsonl`。
